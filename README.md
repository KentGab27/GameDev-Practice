# GameDev-Practice 1
## Description
Apple Catcher is a simple Unity game in which players collect falling apples to earn points while dodging falling sawblades that reduce health. The project was created to strengthen core Unity development skills, including tilemap creation, collision detection, player controls, UI implementation, health systems, and score management.
<img width="800" height="500" alt="Screenshot (5589)" src="https://github.com/user-attachments/assets/3af6525c-d62a-4a9f-b36f-826ceed4be98" />

## How to Play:
- Press A to move left and D to move right
- Avoid sawblades and collect apples until timer runs out
